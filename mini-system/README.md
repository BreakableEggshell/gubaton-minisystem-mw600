# Mini System — Tasks

A small static web app: 3 plain HTML pages providing interfaces for viewing,
adding, editing, and deleting task records. No JavaScript logic, no backend
— markup and styling only.

## Running it

Open `index.html` directly in a browser, or serve the folder with any static
file server, e.g.:

```bash
npx serve .
```

## Structure

- `index.html` — view all tasks, with links/buttons for edit and delete
- `add.html` — form interface for adding a new task
- `edit.html` — form interface for editing or deleting an existing task
- `css/style.css` — shared styles
